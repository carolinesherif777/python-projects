# 🎯 Number Guessing Game

A simple and interactive Number Guessing Game built with **Python** and **Tkinter**.

The game randomly generates a number between **1 and 50**, and the player has **10 attempts** to guess it correctly. After each guess, the game provides a hint indicating whether the guessed number is too high or too low.

---

## ✨ Features

- 🎲 Random number generation
- 🔢 User-friendly graphical interface (GUI)
- 📉 Hint when the guess is too low
- 📈 Hint when the guess is too high
- 🎉 Win message when the correct number is guessed
- ❌ Game Over message after all attempts are used
- 🔄 Remaining attempts counter
- ⚠️ Input validation using message boxes

## 🎮 How to Play

1. Launch the game.
2. Enter a number between **1 and 50**.
3. Click **Guess Number**.
4. Read the hint:
   - 📉 Too Low
   - 📈 Too High
5. Keep guessing until you find the correct number or run out of attempts.
